6What is a cycle?💡 A cycle is a compilation of decisions within a specific functional area, with each functional area corresponding to one of the five input parameters.

Each cycle signifies the same three-year period and permits the modification of one input parameter. Consider each cycle as a new baseline, allowing for the gradual refinement of our plan over the designated time span.

Note that only one input parameter can be edited per cycle, and to modify multiple parameters, it is necessary to generate new cycles.
